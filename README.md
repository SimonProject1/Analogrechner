# Analogsignal-Rechner

## GitHub Pages
1. Alle Dateien in den Hauptordner des Repositorys hochladen.
2. Unter **Settings > Pages** bei **Source** die Option **Deploy from a branch** wählen.
3. Branch **main** und Ordner **/(root)** auswählen.
4. Das Feld **Custom domain** leer lassen.

Auf dem iPhone die veröffentlichte Seite in Safari öffnen und über **Teilen > Zum Home-Bildschirm** hinzufügen.
